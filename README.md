# Кейс-задача № 4

## Условие задачи

Известно, что у дракона может быть несколько голов, и его сила определяется числом голов. Но как определить силу драконьей стаи, в которой несколько драконов и у каждого из них определенное число голов?

Вероятно, можно предположить, что сила вычисляется как сумма всех голов. Однако это не так. Сила драконьей стаи равна **произведению** количества голов каждого из драконов.

Например, если в стае 3 дракона с 3, 4 и 5 головами соответственно, то сила равна:

```text
3 × 4 × 5 = 60
```

Известно суммарное количество голов драконьей стаи **N**. Необходимо определить максимально возможную силу стаи.

**Ограничение:** у одного дракона может быть не более **7 голов**.

### Входные данные

Натуральное число **N**, где:

```text
0 < N < 100
```

### Выходные данные

Максимально возможная сила драконьей стаи.

---

# Идея решения

Чтобы произведение было максимальным, выгодно разбивать число **N** на как можно большее количество семёрок, поскольку максимальное количество голов у одного дракона равно **7**.

### Примеры

```text
N = 14
14 = 7 + 7
Сила = 7 × 7 = 49
```

```text
N = 15
15 = 7 + 7 + 1
Сила = 7 × 7 × 1 = 49
```

```text
N = 16
16 = 7 + 7 + 2
Сила = 7 × 7 × 2 = 98
```

---

# Алгоритм решения

1. Пока `N > 7`, выделяем дракона с 7 головами.
2. Умножаем текущий результат на 7.
3. После завершения цикла умножаем результат на оставшееся количество голов.

---

# Программа на Python

```python
n = int(input())

power = 1

while n > 7:
    power *= 7
    n -= 7

power *= n

print(power)
```

# Пример работы

### Ввод

```text
16
```

### Разбиение

```text
16 = 7 + 7 + 2
```

### Сила

```text
7 × 7 × 2 = 98
```

### Вывод

```text
98
```
